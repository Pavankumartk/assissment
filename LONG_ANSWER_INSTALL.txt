Long Answer / Essay - Creator and Viewer integration

Files: Long Answer Content screen, Long Answer Preview screen, type-specific Details/Evaluation/Review/Viewer copies, plus minimal shared type/routing/storage/results registrations.

The Content page is available at the existing shared route /assessments/create/content when a "Long Answer" assessment is selected. Preview Questions opens the Preview screen, whose Back / Edit / Save And Continue actions operate on the saved Long Answer draft.

The existing Details, Evaluation, Review, Viewer Instructions, Submit dialogs, Header and Sidebar designs of other assessment types are unchanged.

User installation (Mac):
cd ~/Desktop/assessments/web
cp -R src ../src-before-long-answer
unzip -o ~/Downloads/Assessment_Long_Answers_Content_Preview_Integrated.zip -d .
rm -rf .next
npm run build

This update saves data in browser localStorage scoped by active assessment ID. Long Answer responses await grading rather than receiving an automatic correctness score.

Source project TS checking completed successfully. Production build and pixel-level browser comparison are not verified on the user's Mac.
