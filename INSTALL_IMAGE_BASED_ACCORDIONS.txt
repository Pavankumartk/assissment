INSTALL ON MAC:
 cd ~/Desktop/assessments/web
 unzip -o ~/Downloads/Image_Based_Create_Questions_Accordions_Only.zip -d .
 npm run build
 npm run dev

OPEN THE EXISTING IMAGE-BASED CREATE QUESTIONS FLOW.
Click "Question and Image", "Answer Options", "Grading Method", and "Feedback".
All four can remain expanded simultaneously as shown in the screenshot.
